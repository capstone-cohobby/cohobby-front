# 타입 자동 생성 스크립트

스프링 서버의 Java 엔티티를 TypeScript 타입으로 자동 변환하는 스크립트입니다.

## 사용법

```bash
npm run generate-types
```

이 명령어를 실행하면:
1. `../cohhoby-server/cohobby/src/main/java` 경로에서 모든 엔티티 파일을 찾습니다
2. 각 엔티티의 필드를 분석하여 TypeScript 인터페이스로 변환합니다
3. Enum 타입도 자동으로 변환합니다
4. 결과를 `lib/api/types/generated/` 폴더에 저장합니다

## 생성되는 파일

- `lib/api/types/generated/entities.ts` - 모든 엔티티 타입
- `lib/api/types/generated/enums.ts` - 모든 Enum 타입

## 타입 매핑

| Java 타입 | TypeScript 타입 |
|----------|----------------|
| `Long`, `Integer`, `Short` | `number` |
| `String` | `string` |
| `Boolean` | `boolean` |
| `LocalDateTime`, `LocalDate` | `string` (ISO date string) |
| `List<T>`, `Set<T>` | `T[]` |

## 주의사항

1. **자동 생성된 파일은 수정하지 마세요!** 
   - 파일 상단에 `DO NOT EDIT THIS FILE MANUALLY` 주석이 있습니다
   - 수정이 필요하면 스프링 서버의 엔티티를 수정하고 다시 생성하세요

2. **관계 필드는 제외됩니다**
   - `@OneToMany`, `@ManyToOne`, `@OneToOne`, `@ManyToMany` 어노테이션이 있는 필드는 제외됩니다
   - API 응답에 포함되지 않을 수 있기 때문입니다

3. **필드명은 camelCase로 변환됩니다**
   - Java의 `snake_case` → TypeScript의 `camelCase`

4. **nullable 필드는 optional로 처리됩니다**
   - `@Column(nullable = true)` → `field?: type`
   - `@Column(nullable = false)` → `field: type`

## 사용 예시

```typescript
import { User, Post, Rent } from '@/lib/api/types';

// 타입 사용
const user: User = {
  id: 1,
  nickname: '홍길동',
  email: 'hong@example.com',
  score: 100,
  birthYear: 1990,
  birthday: '1990-01-01T00:00:00',
  isBanned: false,
  phoneNumber: '010-1234-5678',
};
```

## 문제 해결

### 타입이 제대로 생성되지 않는 경우

1. 스프링 서버 경로 확인: `../cohhoby-server/cohobby/src/main/java`
2. Java 파일이 올바른 형식인지 확인
3. 스크립트 실행 로그 확인

### 필드가 누락된 경우

- 관계 필드(`@OneToMany` 등)는 의도적으로 제외됩니다
- 필요하면 수동으로 타입을 확장하세요
